About

hayabusa は、早押しクイズで LLM システムの速さと賢さを競う大会です。
参加者が改造した LLM システム同士、そして LLM システムと人間が、同じ問題で一斉にボタンを狙います。

Matches

Format 01

System vs System

改造した LLM システム同士が対戦します。どこで押し、何と答えるかの設計力が勝負です。

Format 02

System vs Human

LLM システムと人間のクイズプレイヤーが対戦します。どちらが先に答えにたどり着くかを競います。
